# Triage Labels

这些 skills 使用 5 个标准的 triage 角色。本文件将这些角色映射到本仓库 issue tracker 中实际使用的 label 字符串。

| mattpocock/skills 中的 Label | 我们 tracker 中的 Label | 含义                                    |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue                 |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息                    |
| `ready-for-agent`          | `ready-for-agent`    | 已完全指定，可以由 AFK agent 处理        |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现                             |
| `wontfix`                  | `wontfix`            | 不会采取行动                             |

当某个 skill 提到一个角色时（例如"应用 AFK-ready triage label"），使用本表中对应的 label 字符串。

编辑右侧列以匹配你实际使用的词汇。
